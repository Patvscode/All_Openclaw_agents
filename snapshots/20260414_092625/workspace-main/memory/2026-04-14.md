### Scene Switching Pipeline
- 3-step Docker pipeline: Florence-2 caption → DA3 depth → point cloud render (~3-5 min first time)
- Preprocessed data cached in `user_input/new_vggt/<video_name>/` — subsequent switches skip pipeline (~1-2 min model warmup only)
- Pipeline commands: `gen_json.py --root_dir --model_path`, `run_da3_parallel.py --json_path --gpu_list --da3_cli --da3_config --convert_script`, `run_render_parallel.py --json_path --gpu_list --render_script --traj_txt_path --width --height --relative_to_source`

### Bugs Found & Fixed
- **Frame delivery blocked** — `sorted(glob.glob(...))` on 1000+ files every 40ms was too slow; replaced with sequential probe by frame index
- **.mov uploads invisible to pipeline** — gen_json.py only finds .mp4; added auto-conversion on upload
- **Dual DiT processes** — `pkill` from host can't reach inside Docker container; fixed scene switch to use `docker exec pkill -9 -f dit_stream`
- **user_input/ owned by root** — Docker setup changed ownership; fixed with chown
- **Joystick touch handling** — iOS Safari stole touches; fixed with per-touch-ID tracking, preventDefault+stopPropagation, disabled callout/selection

### Known Issues (not yet fixed)
1. `get_available_scenes` lists both .mov and .mp4 versions of same video (visual duplicate)
2. `stop_dit_stream()` (Stop button) uses host-side pkill — should use docker exec pkill
3. After scene switch mid-session, frame probe starts from old `last_frame_idx + 1` — won't find new frames starting at 0 (glob fallback only fires on first connect)
4. Joysticks wired to pose.json but DiT plays pre-baked trajectory — real-time camera steering not yet connected
5. Quality/steps changes write quality.json but DiT doesn't hot-reload — requires restart
