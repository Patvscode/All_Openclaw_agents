### Key Design Decisions
- **Product philosophy:** "Open by default. Reliable by choice. Dangerous only by consent." — OpenClaw-level customizability with responsible defaults
- **Three-layer model:** Explore (default, read-only agent) → Builder (agent writes/executes) → Full Override
- **Localhost-first:** Binds 127.0.0.1 by default; remote access is explicit user choice with auth
- **Dual status model:** resource.status (coarse: pending/processing/completed/failed) + resource.pipeline_status (detailed: extracting/analyzed/discovered/etc)
- **Proposals use stable UUID proposal_id** — not array index. Decision fields (decision, decision_at, subproject_id, edited_*) stored inline in JSON
- **Normalization on read:** Legacy proposals without proposal_id get backfilled automatically
- **Provider abstraction from the start:** LLMProvider ABC → OllamaProvider + FallbackProvider. Fallback output always clearly labeled as synthetic
- **Job runner disabled in tests** via settings.jobs.disabled (flows through pydantic-settings, not raw os.environ)
- **Path traversal:** resolve() + is_relative_to() check, deterministic 403
