## Late Night Session (~22:46 EDT)

### Gemma Autonomy Upgrade
Pat noticed Gemma says "I'm diving in now" then its turn ends without doing anything. Root cause: model generates text but doesn't follow with tool calls, then the run completes and nothing triggers the next turn until heartbeat.

**Built three things:**
1. **Execution Bias** — instructions to act in the same turn, not just announce
2. **Self-Scheduling** — `openclaw cron add --at "+Xs" --delete-after-run` pattern for continuing work across turns. Agent decides if/when to continue. Max 10 continuations per task.
3. **SCRATCHPAD.md** — mandatory thinking file. Every turn: write plan → read it back → evaluate → then act. Forces deliberate decision-making. Pat can inspect it anytime.

**Key design decisions:**
- Not a dumb timer — agent must justify each continuation
- Written plan must be re-read before acting (catches bad plans)
- Only on Gemma for now — test the pattern on free local model before adding to paid APIs
- `--delete-after-run` prevents cron accumulation
- Single continuation at a time, always named `gemma-continue`

### Future Idea: "Inner Voice" / Anxiety Model
Pat's concept: a tiny persistent model (2B) that acts as Gemma's sense of urgency/accountability.

- Separate from the scratchpad (which is about decision quality) — this is about follow-through over time
- Implementation: tiny Ollama model reading scratchpad on a loop, firing cron nudges
- **NOT building yet** — get scratchpad pattern working first, then layer this on
